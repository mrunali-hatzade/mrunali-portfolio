Interactive Playground for Next.js/React Portfolio Websites
===========================================================

This package contains the fully responsive "Interactive Playground" component, featuring:
1. "Build-a-Dev" Matcher & Configurator
2. "Developer Clicker" Passive Clicker Game with LocalStorage state persistence and achievements.

Files included:
- InteractivePlayground.jsx (Standalone React Component)
- InteractivePlayground.css (Cyberpunk glassmorphic styles)

How to integrate:
----------------
1. Copy InteractivePlayground.jsx into your React/Next.js components folder (e.g., components/InteractivePlayground.jsx).
2. Copy InteractivePlayground.css into your styles folder, or copy-paste its content into your globals.css.
3. Import the component in your page:
   import InteractivePlayground from './components/InteractivePlayground';
4. Drop it into your JSX:
   <InteractivePlayground />
5. Make sure to update the skills, categories, and upgrade shop items inside InteractivePlayground.jsx with your own stack!

Enjoy!
